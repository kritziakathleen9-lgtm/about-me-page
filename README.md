## 📱 Diseño Responsive

La página está diseñada para adaptarse a diferentes tamaños de pantalla.

Mediante **CSS Media Queries**, se modifican diferentes elementos cuando la pantalla tiene un tamaño reducido:

- Tamaño de los textos
- Distribución del contenido
- Márgenes y espacios
- Botones
- Imágenes
- Columnas del diseño

De esta manera, la página puede visualizarse tanto en ordenador como en dispositivos móviles.

---

## 🌙 Modo oscuro

La página incorpora un botón de **modo oscuro** desarrollado con JavaScript.

Al pulsarlo, se modifican los estilos de la página para conseguir una apariencia más oscura y cómoda para el usuario.

```text
☀️ Modo claro
      ↓
   [ 🌙 ]
      ↓
🌙 Modo oscuro
```
